# Input Display App & Secret Mini-Game

Welcome to my Python application built using the **Flet** framework! This app serves primarily as an interactive user-input display terminal, but it also features a **secret 3-part mini-game (Easter eggs)** hidden.

---

## Core Features
- **Input Display System:** Type any text into the command field and display it instantly on screen.
- **Dynamic Theme Switching:** Toggles between light and dark visual modes based on user inputs.
- **Secret Mini-Game:** Unlocks a hidden 3-part progression system with progress tracking and celebratory completion screens.

---

# Hidden Easter Eggs & How to Unlock Them
The app contains 3 secret steps that must be unlocked **in order**:
1. **Secret Part 1:** Type `starlight` into the input field to activate Solar Mode.
2. **Secret Part 2:** Type `moonlight` into the input field to trigger the lunar eclipse (requires Part 1 first).
3. **Secret Part 3:** Clear the input field completely and click the **"Display Input"** button 3 times consecutively to initiate the secret warp sequence.

Once all 3 parts are found, a completion message will appear along with a reset button to play the mini-game again!
