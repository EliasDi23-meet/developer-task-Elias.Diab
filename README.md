# Space Station Bravo - Crisis Control

Welcome to **Space Station Bravo - Crisis Control**, an interactive narrative terminal app built using Python and the Flet framework! Take on the role of Mission Control, guide astronaut Maya through critical space station emergencies, and launch a rescue shuttle to save the day.


## Core Features:
- **Multi-Stage Narrative Gameplay:** Progress through different crisis states (`game_stage`) as emergencies unfold at the space station.
- **Dynamic Theme Switching:** Toggle between dark space mode and bright solar observatory modes (`page.theme_mode`) dynamically based on your actions.
- **Interactive Terminal Commands:** Validate secret codes (`starlight`, `moonlight`) through a styled text input field.
- **Multi-Click Launch Sequence:** Charge station thrusters through consecutive button clicks to blast off into space.
